Интеллектуальный сервис планирования рабочих маршрутов инженеров

Решение для задачи «Интеллектуальный сервис планирования рабочих маршрутов для инженеров с учетом временных окон и сложности проводимых работ» в рамках хакатона «Лидеры цифровой трансформации».

О проекте

Сервис автоматически формирует рабочие маршруты инженеров с учетом:

- географического расположения заявок;
- временных окон;
- длительности и сложности работ;
- квалификации и доступных навыков инженеров;
- рабочего времени;
- времени перемещения между точками;
- приоритетов заявок.

На выходе система формирует последовательность заявок для каждого инженера и соответствующий маршрут.

Оптимизация маршрутов

В основе решения используется задача маршрутизации с ограничениями.

Алгоритм учитывает не только расстояние между точками, но и возможность выполнить заявку в заданное временное окно.

Для заявки могут задаваться:

- координаты;
- временное окно;
- тип работы;
- требуемые навыки;
- длительность выполнения;
- приоритет.

Для инженера:

- стартовая точка;
- рабочее время;
- доступные навыки.


Это позволяет учитывать не только время в пути, но и фактическую загрузку рабочего дня инженера.

Временные окна

Для каждой заявки может быть задано допустимое окно выполнения:

[ начало окна ───────── конец окна ]
          ↑
      прибытие
          ↓
    выполнение

Решение допускает раннее прибытие и ожидание, но выполнение работы не начинается раньше разрешенного времени.

Учет квалификации

Заявка может требовать определенный навык.

Перед построением маршрута проверяется соответствие:

Заявка
   │
   ├── тип работы
   ├── требуемый навык
   └── длительность
          │
          ▼
   Подходящие инженеры
          │
          ▼
      оптимизация

Таким образом, маршрут строится только среди допустимых назначений.

Основные компоненты

API

Отвечает за взаимодействие между интерфейсом, данными и модулем оптимизации.


- маршрутов;
- результатов планирования.

OR-Tools

Используется как оптимизационный модуль для построения маршрутов с учетом ограничений.

Routes.ipynb

Ноутбук с разработкой и расчетом маршрутов. Файл находится непосредственно в корне репозитория.

Результат работы

На выходе для каждого инженера формируется:

1. список назначенных заявок;
2. порядок их выполнения;
3. время прибытия;
4. время начала и окончания работы;
5. перемещения между точками;
6. итоговый рабочий маршрут.
