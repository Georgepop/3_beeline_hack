# Интеллектуальный сервис планирования рабочих маршрутов инженеров

Решение для задачи **«Интеллектуальный сервис планирования рабочих маршрутов для инженеров с учетом временных окон и сложности проводимых работ»** в рамках хакатона **«Лидеры цифровой трансформации»**.

## О проекте

Сервис автоматически формирует рабочие маршруты инженеров с учетом:

- географического расположения заявок;
- временных окон;
- длительности и сложности работ;
- квалификации и доступных навыков инженеров;
- рабочего времени;
- времени перемещения между точками;
- приоритетов заявок.

На выходе система формирует последовательность заявок для каждого инженера и соответствующий рабочий маршрут.

## Оптимизация маршрутов

В основе решения используется задача маршрутизации с ограничениями.

Алгоритм учитывает не только расстояние между точками, но и возможность выполнить заявку в заданное временное окно.

### Параметры заявки

Для заявки могут задаваться:

- координаты;
- временное окно;
- тип работы;
- требуемые навыки;
- длительность выполнения;
- приоритет.

### Параметры инженера

Для инженера учитываются:

- стартовая точка;
- рабочее время;
- доступные навыки.

Это позволяет учитывать не только время в пути, но и фактическую загрузку рабочего дня инженера.

---

## Временные окна

Для каждой заявки может быть задано допустимое окно выполнения:

```text
Начало окна                         Конец окна
     │                                  │
     ▼                                  ▼
─────┬──────────────────────────────────┬─────
     │                                  │
     │          допустимый интервал     │
     │                                  │
     └───────────► Прибытие ────────────┘
                    │
                    ▼
                 Работа
```

Инженер может прибыть раньше начала временного окна и ожидать.

При этом выполнение работы не начинается раньше разрешенного времени.

---

## Учет квалификации

Каждая заявка может требовать определенный навык.

Перед построением маршрута учитывается соответствие заявки и инженера:

```text
┌──────────────────────┐
│       Заявка         │
│                      │
│ • тип работы         │
│ • требуемый навык    │
│ • длительность       │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ Подходящие инженеры  │
│                      │
│ • квалификация       │
│ • доступные навыки   │
│ • рабочее время      │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│    Оптимизация       │
│      маршрута        │
└──────────────────────┘
```

Таким образом, маршрут строится среди допустимых назначений.

## Основные компоненты

### API

Отвечает за взаимодействие между интерфейсом, данными и модулем оптимизации.

Используется для передачи входных данных и результатов планирования маршрутов.

### OR-Tools

Используется как оптимизационный модуль для построения маршрутов с учетом заданных ограничений.

### Routes.ipynb

Jupyter Notebook с разработкой и расчетом маршрутов.

Файл находится непосредственно в корне репозитория.

### Front

Пользовательский интерфейс для отображения:

- заявок;
- маршрутов;
- карты;
- результатов планирования.

---

## Результат работы

Для каждого инженера система формирует:

- список назначенных заявок;
- порядок их выполнения;
- время прибытия;
- время начала работы;
- время окончания работы;
- перемещения между точками;
- итоговый рабочий маршрут.

В результате диспетчер получает готовый план работы инженеров с учетом географии, временных ограничений, квалификации и параметров заявок.
